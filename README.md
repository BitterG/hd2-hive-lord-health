# 霸王虫精确血量与定位 (Hive Lord Health & Locator) v2.3.0

适配 **MDL3**（`dev.41+` / `dev.57+` 含 `MDL3.gui` 绘图接口）与 **HD2 Data Hub (0.3.0+)** 的《绝地潜兵 2》霸王虫实时精确 Boss 血量条与战术定位雷达模组（纯只读、零内存写入、跨版本自动适配）。

```text
          霸王虫 HIVE LORD   92,400 / 150,000  (61.6%)
  [████████████████████████████░░░░░░░░░░░░░░░░░]
      实时追踪 LIVE   |   142 m (右前)   |   -57,600 DMG

  +----------------------+        (准星外围动态方向箭头)
  |      霸王虫定位      |             ↗  142m
  |   (  ·  ▲  --> ● )   |
  |    142 m  右前 32°   |
  |   实时 | 范围 250m   |
  +----------------------+
```

## 功能特性

- **实时精确主血量与缓冲血条**：通过 `HD2Data` (API 1) 订阅霸王虫生成、受伤与死亡事件，实时绘制战术金/橙/红三段变色进度条、受击残影缓冲条、精确数值、百分比，以及副标题距离与相对方位。
- **战术定位小雷达（Player-Up，需 `MDL3.gui` / `dev.41+`）**：以你为中心、准星朝向始终向上绘制圆形小雷达，标出霸王虫位置点、相对角度、距离、正北方向 `N` 与队友蓝点参照；目标超出雷达探测半径时自动在边缘显示方向三角标，潜地时在最后位置标记 `潜地` 与经过秒数。
- **准星外围方向箭头（需 `MDL3.gui` / `dev.41+`）**：在屏幕中心外围环绕绘制动态箭头与紧凑距离胶囊（`142m`），近距（`< 60m`）或位于身后时自动切换警示红橙色，转头或移动时 60 FPS 丝滑跟随且零画布重建。
- **潜地保留与破土继承**：霸王虫钻入地下潜行时保留最后已知血量与位置并标记 `潜地 SUBMERGED`；重新破土（即使引擎分配新实体 ID）自动继承剩余血量并立即刷新至新坐标，不会误跳回满血。
- **击杀归零保持**：最后一击触发 `entity_died` 时立即归零显示 `0 / 150,000 (0.0%)` 与 `已击杀 SLAIN`，隐藏准星箭头并在雷达保留击杀位置标记指定秒数后自动淡出。
- **中英双语主动切换 + 原生字体回退**：自动检测游戏与 MDL3 语言并探测原生字体是否支持中文（无中文字体时安全回退英文，绝不出现 `???` 乱码），也可在 `ESC -> MDL 设置 -> 界面语言 (Language)` 或 `hivelord_health.cfg` 中手动选择 `auto` / `zh` / `en` 实时切换；旧版 `MDL3 dev.21..40`（无 `MDL3.gui`）或无原生字体时自动回退并保持血量条及副标题距离显示可用。
- **实时 30 Hz 移动追踪（突破出土点冻结限制）**：在 `HD2Data` 提供事件初始坐标与 `network_id` 的基础上，模组通过只读 `stingray.Network` / `stingray.GameSession.game_object_field_batched` 以约 30 Hz 自动发现并锁定霸王虫及其关联网络对象（含邻近与表引用子对象）中真正随移动变化的 `Vector3` 实时坐标字段，即使霸王虫破土后高速游走且未受击也能连续跟随；当事件接口仍回传旧出土穴坐标时自动屏蔽回弹抖动；若事件缺少 `network_id`，则在 `1..16384` 内分片扫描匹配对象。
- **ESC 菜单实时预览调参与自动保存**：支持在舰桥或任务中按 `ESC -> MDL 设置 -> 霸王虫血量与定位 (Hive Lord HP & Locator)` 调节界面语言、血条位置、雷达开关/探测半径/缩放/坐标与中心箭头半径，实时置顶预览并自动持久化到本地配置文件，重启游戏自动恢复。

> 说明：默认优先使用 `GameSession` 实时 `Vector3` 坐标（状态文件与日志中记为 `pos_src=goid_live`）；若某场对局尚未锁定移动对象或会话句柄暂不可用，则自动平滑回退到 `HD2Data` 的生成、破土、受击与击杀事件坐标（`spawn` / `resurface` / `hit`），并在长时间无更新时标注最后位置已过秒数。

## 前置依赖与安装步骤

1. **安装前置（必需）**：
   - **MDL3**（推荐 `MDL3-3.0.0-dev.57-preview` 或任意 `dev.41+` 版本以启用 `MDL3.gui` 战术雷达与方向箭头；`dev.21..40` 仅支持血量条与副标题距离），在模组管理器中同时勾选 `MDL3` 与 `HD2 Data Hub` 并**将 `MDL3` 放在最高优先级（最后部署）**。
2. **导入本模组**：
   - 在 Arsenal / HD2 Mod Manager 中导入 `HiveLord-HP-Health-2.3.0.zip`，勾选启用 **霸王虫血量与定位模组本体 (Hive Lord Health)**。
3. **部署并启动游戏**：
   - 点击 **Purge（清理） -> Deploy（部署）**，启动游戏即可。

## 游戏内设置与配置文件

- **游戏内实时调节与自动持久化（推荐）**：
  进入游戏后按 `ESC` 打开 **MDL 设置**，找到 **霸王虫血量与定位 (Hive Lord HP & Locator)**，可实时调整并**自动保存至本地 `hivelord_health.cfg`**（重启游戏后自动恢复）：
  - 血条显示开关、舰桥预览开关（同时预览血条、战术雷达与中心箭头；仅当次预览，重启自动归位关闭）
  - 界面语言切换（`auto` 自动跟随游戏/MDL3、`zh` 强制中文、`en` 强制英文，即时生效并保存）
  - 血条位置（顶部居中 / 底部居中）、界面缩放 (`0.50x` – `2.50x`)、垂直边距 (`10` – `540 px`)、水平偏移 (`-600` – `600 px`)、不透明度 (`0.20` – `1.00`)、实心进度条开关、击杀后保留秒数 (`0` – `15 s`)
  - 战术定位雷达开关、中心方位箭头开关、血条副标题显示距离开关、雷达显示队友位置开关
  - 雷达探测半径 (`100` – `500 m`)、雷达大小缩放 (`0.60x` – `2.00x`)、雷达水平/垂直偏移、方位箭头环绕半径 (`80` – `360 px`)

- **本地配置文件（双向同步）**：
  首次运行会在以下目录自动生成（**启动时绝不覆盖已有手改配置**；游戏内菜单修改时自动写回保存；删除文件后重进游戏可恢复默认）：
  ```text
  %APPDATA%\Arrowhead\Helldivers2\hivelord_health.cfg
  ```

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `hud` | `true` | 是否在屏幕绘制血量条（设为 `false` 时仅记录日志，可独立保留雷达/箭头） |
| `language` | `auto` | 界面语言：`auto`（自动跟随游戏/MDL3）、`zh`（中文）或 `en`（英文） |
| `hud_position` | `top` | 血条锚点位置：`top`（屏幕上方罗盘下）或 `bottom`（屏幕下方） |
| `hud_scale` | `1.00` | 在 1080p 自适应基础上的额外缩放倍率 |
| `hud_offset_y` | `135` | 距离顶部或底部边缘的基准像素边距 |
| `hud_offset_x` | `0` | 距离屏幕水平中心的基准像素偏移（负数偏左，正数偏右） |
| `hud_alpha` | `0.90` | 整体不透明度 (`0.20` – `1.00`) |
| `hud_bar` | `true` | 是否绘制实心进度条与受击残影槽 |
| `locator_radar` | `true` | 是否显示以玩家为中心的战术定位小雷达（需 `MDL3.gui`） |
| `locator_pointer` | `true` | 是否在屏幕中心外围显示指向霸王虫的方位箭头与距离（需 `MDL3.gui`） |
| `locator_bar_distance` | `true` | 是否在血条副标题中同时显示当前距离与相对方位 |
| `locator_squad` | `true` | 是否在战术雷达上用蓝点显示队友位置 |
| `locator_range` | `250` | 战术雷达外圈对应的实际探测半径（米） |
| `locator_radar_scale` | `1.00` | 战术雷达大小缩放倍率 |
| `locator_radar_x` | `770` | 雷达中心相对屏幕水平中心的偏移（1080p 基准像素） |
| `locator_radar_y` | `-180` | 雷达中心相对屏幕垂直中心的偏移（负数偏上） |
| `locator_pointer_radius` | `165` | 中心方位箭头环绕屏幕中心的半径（1080p 基准像素） |
| `burrow_hold_seconds` | `60.0` | 霸王虫潜地后保留血条与定位显示的秒数 |
| `death_hold_seconds` | `5.0` | 霸王虫被击杀归零后保留显示的秒数 |
| `debug` | `false` | 是否将每次细微受击写入详细日志 |

## 状态自检与故障排查

运行状态与日志位于 `%APPDATA%\Arrowhead\Helldivers2\`（若受限则回退至 `%LOCALAPPDATA%\MDL3\` 或 `C:\ProgramData\MDL\Helldivers2\`）：
- `hivelord_health_STATUS.txt`：实时输出当前配置状态与霸王虫精确生命值。
- `hivelord_health.log`：完整运行日志。若提示 `HD2Data global not found yet`，请检查模组管理器中是否勾选启用了 **HD2 Data Hub**。
