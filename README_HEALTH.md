# 霸王虫精确血量 (Hive Lord Health) 1.10.0

在屏幕上显示霸王虫的**精确血量**（当前 / 最大）。

## 安装

1. 需要 **Bingus Shared Loader v18**
2. 导入 `HiveLord-HP-Health-1.10.0.zip`，启用 Core
3. Purge → Deploy
4. 进游戏，打霸王虫

## 不想看血条

配置文件由 mod 自己生成：

```
%APPDATA%\Arrowhead\Helldivers2\hivelord_health.cfg
```

把 `hud` 改成 `false`，血条就不显示（只记日志）。
